# UNIB Belakang Navigation

Web-based campus navigation system for Universitas Bengkulu Belakang using Dijkstra shortest path algorithm.

## Features

- Dynamic shortest path navigation
- One-way road simulation
- Gate open/close regulation based on time and day
- Interactive digital map using Leaflet.js
- Route visualization with step-by-step navigation

## Technologies

- HTML
- JavaScript
- Tailwind CSS
- Leaflet.js
- OpenStreetMap

## AI Concept

This project applies graph-based artificial intelligence using dynamic constraints.

The routing system can adapt to:

- traffic direction changes
- gate access rules
- time-based road conditions

## Demo

The system calculates the best route dynamically based on user-selected conditions.
